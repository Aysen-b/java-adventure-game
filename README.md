# Java Adventure Game

This is a console-based adventure game developed using Java.

## Features
- Character selection
- Battle system
- Different locations (Cave, Forest, River)
- Enemy types (Zombie, Vampire, Bear)

## Technologies
- Java
- Object-Oriented Programming (OOP)

## How to Run
Run the Main.java file.

## Project Structure
- Player.java → player logic
- Location.java → base class
- BattleLocation.java → combat system
- Game.java → main game flow
